# v0.10：核对比较方向与资料步骤

本轮延续Issue 10中的有限意图核对工作：原文关联和可重算不能发现所有操作类型错误，也不能证明比较方向符合问题。目标是对明确的有限句式增加可解释检查，继续对其他表达保守跳过。

1. 新增完整句式核对：以当前快照中的明确run ID指定比较基线/候选，和三类固定资料说明请求。发现方向颠倒、错误操作、重复或缺少步骤；引用、指代及未知句式不推断。
2. 生成API启用新核对；与已有查询规则共享最多两次请求，提供提案字段反馈。原始错误与实际请求继续保留，不自动改写或执行。
3. 预览和执行结果展示“比较与资料步骤核对”，增加可运行的离线示例；手动冲突仍可检查与执行，但明确提示。收据格式保持兼容，重算不证明任务正确。
4. 提前冻结6道新组合任务，使用已公开的DPO真实摘要和Atlas合成快照。相同v2提示与格式下开/关核对，两组各两次，共24个draw，每个最多两次请求。另将3种预声明人为错误作为独立修正实验，每例最多一次真实修正，不计入自然模型成绩。
5. 完成工程测试、历史收据、浏览器、安装包、两套Python CI与GitHub发布；更新主页和讲解材料。公开失败、原始输出、费用与证据边界。

新任务使用既有数据，不是第二个真实实验项目或外部独立测试。资料规则只检查是否调用describe并展示原文，不证明资料已经回答全部语义问题；通用语义验证与独立人工审核继续未完成。
