# v0.11：可分享的分析报告

当前结果以可重算JSON为主，外部评审仍需安装项目或进入工作台才能阅读。此次增加静态HTML和Markdown导出，让已有结果可以直接阅读，同时保留完整数据、条件、原文说明及证据边界。

1. 接收现有查询/计划收据，先校验哈希并使用其中的数据重算。任何字段、格式或重算不一致都拒绝导出；不读取来源标签指向的文件或网站，不调用模型。
2. 生成自包含HTML与Markdown：完整有序结果、比较方向和差值、单位、原文说明、来源标签、合成标记、未处理事项、快照及收据哈希、可复制原始JSON。计划检查标明由当前版本重新执行，不冒充执行当时的检查。
3. 在查询结果、计划结果和离线复核页加入报告下载，并提供命令行入口。页面输入改变、新文件、验证失败及迟到响应不得复用旧导出状态。
4. 预先定义边界和负例矩阵，回放历史收据，验证篡改、重新计算哈希后的伪造结果、空结果/并列/大量行、反向比较、未处理任务及恶意文本。进行真实浏览器下载与离线阅读检查。
5. 完成工程测试、安装包与CI，发布示例报告、使用说明、评测记录及GitHub版本，更新个人主页。

本轮是离线交付能力验证，模型调用数为0，不新增模型效果或自然任务成功率结论。原JSON格式和规划器保持兼容。报告可被编辑，哈希不是签名；重算仅证明内部一致，不认证来源，也不证明自然语言任务被正确完成。计划中的有限规则冲突仍必须明确展示。
