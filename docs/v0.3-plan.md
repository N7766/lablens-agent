# v0.3 五步迭代计划

1. **输出与请求对应**：结构化 submit_answer、直接回答 JSON Schema、显式动作请求的共享只读规则。验收：真实接口联调、错误反馈与零调用拒绝测试；规则拒绝单独计数。
2. **结论边界证据化**：限制自由生成 limitations，改用已读 note IDs 由服务端呈现；数值与引用继续校验。验收：未读说明、编造局限和漏选/乱序结果的失败用例。仍不声称验证所有自然语言含义。
3. **确定性查询**：复合筛选、严格基线改进、排序、并列、Pareto。验收：完整集合、顺序、边界、空集合及不兼容数据测试。
4. **更强对照**：旧题仅作回归；冻结12道新组合题，Agent、单次直接回答、最多8次修正的直接回答三组，各重复2次。每组相同资料与最终字段校验；公平性限制写清楚，保留失败与未知用量。
5. **交付**：更新本地界面、文档、公开轨迹、主页与版本；CI两种Python通过后发布v0.3预发布。正式简历不改动。

具体结果和各步完成证据以 v0.3-evaluation.md 为准。没有独立人工评审，模型效果不预设目标分数；完成评测不等于每题通过。
