2026-10-16。本轮把已有查询/计划结果交付为可读的HTML和Markdown：先校验收据，再从文件内数据重算，展示完整有序结果、条件、比较方向、资料来源和未处理要求。[五步计划](v0.11-plan.md) · [使用说明](v0.11-workbench.md) · [三个示例](reports/v0.11/README.md)。

**457项工程测试通过；166份历史收据的332份导出与22类边界的44项检查，合计376/376通过。本轮模型调用0次。**这是交付能力、兼容性和数据一致性验证，不是新的模型效果、独立人工审核或任务成功率。

## 已交付能力

- `reporting.export_report`和`POST /api/report/export`共用验证及确定性渲染。原查询/计划收据格式不变，规划器、模型提示和意图规则未改变。
- HTML内联样式、无脚本或外部资源；文字转义并限制内容加载。Markdown原文使用足够长的代码围栏，保留换行、管道及反引号；表格特殊字符单独处理。完整原始JSON可复制后重新验证。
- 页面支持当前查询、当前计划及离线复核后的下载；输入变化、失败和迟到响应不能复用旧结果。报告HTML只下载，不插入工作台页面。
- CLI要求显式输出路径；验证或渲染失败不修改目标文件，写入使用临时文件原子替换。拒绝同一路径、大小写或硬链接别名覆盖输入收据。
- 报告将重算通过与任务检查分开，注明有限规则为当前v0.11.0重新核对。未知表达保留未核对；没有原问题的查询收据不补写问题，也不推断历史调用与费用。

## 复现

```bash
pytest -q
python scripts/evaluate_reports.py --output reports/v0.11-report-controls
lablens report docs/reports/v0.11/correct-plan.json --format html --output reports/example.html
lablens report docs/reports/v0.11/manual-reverse.json --format markdown --output reports/reverse.md
lablens verify docs/reports/v0.11/manual-reverse.json
```

报告可编辑、可复制，内容哈希不是签名。导出不提供持久会话、自动多轮记忆、外部真实实验泛化或公网用户隔离。第二个真实实验项目、独立人工评审与通用语义验证继续未完成；[Issue 10](https://github.com/N7766/lablens-agent/issues/10)保持开放。
