# 把分析结果交给评审者

v0.11可以将查询或分析计划的可复核JSON生成HTML和Markdown报告。导出在本机先验证哈希、再用文件内的数据重新计算；不需要配置模型，也不产生新的模型请求。

## 从页面导出

1. 在“条件查询”或“分析计划”执行后，选择HTML或Markdown报告。HTML可以直接在浏览器打开，也可以使用浏览器打印；Markdown适合放入GitHub或文本笔记。
2. 对过去保存的结果，在“离线复核”上传原JSON。复核通过后，同样可以下载报告，无需重新提问或调用模型。
3. 报告包含结果、条件、比较方向、资料原文、来源标签、未处理要求及可复制的原始收据。分享前检查其中的数据是否适合公开。

修改数据、问题或计划后，旧报告入口失效；新文件复核失败也不会保留旧文件的下载许可。报告是静态文件，阅读时不需要运行LabLens服务。

## 从命令行导出

```bash
lablens report receipt.json --format html --output report.html
lablens report receipt.json --format markdown --output report.md
lablens verify receipt.json
```

输入必须是查询或计划的原始收据JSON，不是整份模型轨迹或已导出的HTML/Markdown。文件格式、哈希或重算结果有误时拒绝导出，已有输出文件不会因验证失败被覆盖。

## 怎样解读报告

- “重算通过”表示文件内的数据、参数和列出的结果相符，不证明实验来源真实，也不证明自然语言问题被正确完成。
- 原收据未保存执行当时的规则报告，因此计划部分标为**按当前v0.11.0规则重新核对**。发现方向或条件冲突会保留冲突，不会因为重算通过而改成任务成功。
- 查询收据没有原始自然语言问题，报告不会补写问题。收据也不含历史模型用量，不能据此推断过去免费或调用数为0；“0次模型调用”仅指此次报告生成。
- 表格保留全部有序记录和实际单位，合成记录继续标记。来源路径和网址仅作为文本显示，不会访问或自动导入额外文件。
- HTML/Markdown都可以被编辑；可见哈希不是数字签名。需要重新验证时使用原JSON，或从报告中的原始收据区复制JSON后复核。
