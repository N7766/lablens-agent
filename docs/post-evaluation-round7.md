## 从真实输出确认的两个问题

1. [cedar-t1 原始任务](evaluations/conversation-round7/runs/round7-once/cedar-t1-final-task.json) 的八条草稿已含“Dune未通过C-21验收”“Reed通过C-21验收”。有限匹配器只识别“通过验收”及旧位置的试验范围，没有识别“通过 + 试验ID + 验收”。它误补两条，触发八行容量拒绝，在 review 前明确停止，后续两轮因此阻断。这是可定位的程序误拒绝，不能归因于资料没检索。
2. [harbor-t1 原始任务](evaluations/conversation-round7/runs/round7-once/harbor-t1-final-task.json) 的五条草稿已有“Quill 不通过验收，Sable 也不通过验收”。匹配器没识别“也”，给 Sable 加了第六槽。最终模型在该槽的 Sable 标题下写了 Quill 的失败原因及 Quill 引文。确认冗余槽的来源及最终对象错配，但不能证明去掉槽就必然使另一轮模型完整正确。

两份原稿先写成离线回放测试，在 v2 上实际出现 **2 个失败**：Cedar 抛容量异常，Harbor 准备稿比原稿多一行。保留原稿后再修改实现，没有把旧模型失败改成通过。

## 最小改动

仅修改 [answer_coverage.py](../lablens/answer_coverage.py) 的整体命题识别：

- 支持有限、大写字母起始且包含数字的试验 ID 出现在“通过/满足”与“验收”之间，例如 `T-35`、`TEST12`、`AB_2028`。没有编码真实题目的对象名、ID或阈值。排除大小写 `P/p + 数字` 的百分位标签，不把 `P99/P95` 当试验 ID。
- 支持“也/均/都”位于整个候选的通过/不通过谓词前；现有带因果解释的整体判定及 Round 6 Harbor 修复保持。
- 条件句、假设、是否/能否/问号等不算已给出的整体命题；按句界和当前明确候选定位作用范围，另一候选的问句不抹除本候选已有判定。仅在明确子句边界识别新候选主语；显式联合主语共享范围，因果宾语不另起主语。共同前置条件与本候选的后置条件仍保留；`若干` 不当条件词。换行保持为空白，不截断后续分项限定。
- 时延/成功率等分项，或“验收条件 1”“验收（延迟指标）”，不自动算候选总判定。数值、真伪、证据是否支持仍交给既有 review；词法存在不证明语义正确。

八行上限、原 statement 不变、中性补槽、真满容量明确停止均保持。没有新增模型调用，没有执行模型生成代码，没有提高时间或 token 上限。

## 独立复审发现与修复过程

另一开发侧 AI 只读复审发现两个 v3 初稿回归，已先加例复现：

1. **大写百分位漏防。** 原负例只覆盖 `p99`，大写 `P99/P95` 被通用 ID 形式误接纳，导致分项假冒总体项。新增 `P99/P95/P50/P100` 与小写、带小数形式控制；将 `P/p + 数字` 标签排除出有限试验 ID。
2. **另一候选的问句污染本候选。** `Birch通过验收，Maple是否通过验收？` 被全 statement 疑问扫描误认为两个对象都缺结论；七行稿误补两槽会容量失败。现在只把问句归于对应的候选片段，仍保留当前候选前置/后置条件。该七行稿仅补 Maple，恰好八行；反向候选顺序也有控制。

次要反例 `Birch通过T-35验收，若干资料已归档。` 因单字“若”误触发，改为排除“若干”。这次复现组合共 **9 fail、4 pass**，并新增五项前置/后置条件控制。首次实现句界切分时又触发原有 `Quill通过验收\n成功率指标。` 负例：把换行当句界截掉分项限定。保留原失败，移除换行句界后相关 **142 项全部通过**。这些都是工程测试的实际失败/修复，不是额外模型采样或泛化指标。

随后复审发现“见到另一个候选名就切分”仍会误切原因宾语和联合主语：`Birch 因 Maple 的故障而未通过验收。` 被错误补 Birch；`Birch 与 Maple 总体均未通过验收。` 及“和 Maple 的总体结论”也错误补 Birch。这三项先加入测试，实际 **3 fail**。按明确逗号/句界识别新主语，用有限和/与/及/、/and 连接识别联合主语；因果句中的 Maple 不作为新主语。加上联合问句、前置条件两个负例后，相关 **147 项全部通过**。停止继续扩展自然语言解析范围，保留下面的限制。

仍有明确边界：本实现依赖当前明确命名候选及有限条件词，不解析任意自然语言条件辖域；同句前置条件可能作用于后续多个候选，采用保守处理。它只减少已知冗余补槽，不能替代语义覆盖或实体引用一致性评阅。
