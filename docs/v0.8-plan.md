# v0.8：导入数据上的可核对分析计划

## 阶段目标

让用户对自己的合法格式实验摘要完成导入、规划、预览、执行和离线复核。沿用有限请求规则，验证跨快照数据绑定；不把合成数据测试称为真实外部项目泛化。

## 五步交付与验收

1. **单次请求的数据上下文。** 自动规划接受DatasetBundle，把同一规范化副本用于模型输入与预览；轨迹记录快照与输入数据。默认内置接口保持兼容，不写全局数据。模型数据正文限制128 KiB，过大仍允许不调用模型的手动预览。
2. **可见的数据发送选择。** 分析计划页单独导入/切换数据，展示条目、单位和快照；仅用户明确选择发送当前快照后允许自动生成。服务端要求确认的快照指纹与实际数据一致。切换或导入失败立即清空旧草稿、预览、执行结果与发送选择，过期网络响应不得复活旧状态。导出文件包含数据，需要在下载前可见说明。
3. **单位及引用边界。** “词”阈值在tokenizer token数据上不标已核对；不自动换算。筛选基线字段明确只接受当前快照的实际run ID，错误反馈提示可用ID。未知句式及比较/说明的通用语义仍未验证。
4. **冻结跨快照验证。** A/B为相同ID、不同数值与排名的合成快照；C使用tokenizer单位。预先写定6题合同与预期成员/方向，离线检查后冻结数据、代码、提示词与判据，再每题进行两次真实模型运行；保留所有失败、费用和哈希。这里是预声明合同检验，没有独立人工评分，不是对v0.7的因果提升对照。
5. **交付。** 完整回归、浏览器导入/切换/授权/结果复核/移动布局、安装包与Python3.11/3.13 CI；发布代码、安装包、报告和个人主页更新。Issue 10仍开放。

## 边界

这是本地单用户研究工作台，不提供账户、云端数据存储或公网多租户服务。指纹绑定数据，不认证来源。合成快照中的模型、tokenizer及测量均为测试标签，不是真实训练结果。上传的记录、说明及来源标签会在明确生成时发送给已配置的模型服务，手动预览与执行不调用模型。
