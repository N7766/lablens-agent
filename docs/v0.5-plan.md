# v0.5 三轮更新计划

目标：让“筛选 + 比较 + 说明”的混合请求可以逐项查看、修正和重算。

1. **保留混合证据**：查询后继续展示工具计算的比较，以及已读方法说明、缺失字段。模型自由文字不覆盖这些结果。
2. **可核对分析计划**：单次模型生成有限的查询/比较/资料说明步骤；每步关联问题原文。用户可编辑计划并预览实际条件，再按绑定数据快照的计划执行。比较可以引用此前查询的唯一结果；出现并列时明确拒绝替用户选择。支持完整计划 receipt 与离线复核。
3. **新题验证与发布**：先做开发题，冻结新的混合保留题后比较工具循环和单次规划器；两者共享确定性呈现。保留原始失败、用量、源码与评分边界，完成浏览器流程、CI 和版本发布。

计划原文引用检查只保证引文存在，不证明语义正确或需求无遗漏。执行完成只表示列出的步骤完成；没有独立人工审核，不声称任意自然语言意图自动验证。自定义数据的计划预览/执行仍在本地；网页模型规划仅接收内置数据。
