# v0.4 三轮更新计划

## 第一轮：查询结果与实际条件对应

- 为每份规范化数据生成snapshot ID，查询ID同时绑定数据和参数。
- Agent读取查询后由服务端呈现完整表格、排序规则、筛选条件与已读局限；保留原模型消息用于审核。
- 自由提问的查询条件仍由模型选择，显式标注未确认；不宣称自动理解全部用户意图。
- 验收：旧并列错误复现、空集、多查询、跨快照ID、完整数据表测试。

## 第二轮：个人数据与可复核查询

- 上传标准实验数组或包含runs/notes的bundle，在本地验证，不将导入数据自动发送到模型。
- 提供可编辑条件、预览、执行；预览绑定快照和参数，改动后必须重新预览。
- 导出包含数据、参数、结果与摘要哈希的receipt，支持离线重算。
- 验收：自定义单位、请求隔离、重复ID、无效数据、预览失效、篡改结果检测。

## 第三轮：复核与发布

- CLI提供数据检查、确定性查询、receipt复核；界面支持导入及复核。
- 冻结新的小型组合题，三种方案各重复两次；保留全部轨迹、用量和助手评分。
- 完成离线测试、浏览器关键流程、两版本Python CI，发布v0.4预发布并更新主页。
- 无独立人工审核，不使用工程测试或规则拒绝冒充模型成绩。

每轮单独提交。具体测试数和真实结果以最终交付报告为准。v0.3历史记录保持原样。
