# v0.10：核对比较方向与资料步骤

分析计划在查询条件之外，新增“比较与资料步骤核对”。预览和执行结果都会显示受支持的明确命名比较要求、基线 → 候选方向，以及是否安排查看资料步骤。每项均保留对应原文、关联步骤和原文要求与实际参数的对照表；方向反转、缺失步骤、错误步骤类型或无法唯一匹配会分别展示。

核对只覆盖有限句式。资料步骤匹配只表示计划安排了 `describe`，不代表原文资料已解释正确；未支持的句式与额外步骤会单独列出。完整语义验证仍未执行，不能把“匹配”当作整个问题已正确完成。

## 离线体验

打开“分析计划”，点击“比较与资料核对示例（离线）”。示例恢复内置数据，以 `run:sft` 为基线、`run:dpo-best` 为候选，查询最高准确率并列记录，再查看验证集和显著性边界。载入后自动预览，不调用模型；确认后才执行。

如需观察方向冲突，可展开计划编辑器，互换比较步骤中 `baseline` 与 `candidate` 的 `run_id`，再点击预览。核对表将同时显示原文要求和当前方向。此修改是手动引入的测试错误，不是模型生成的失败案例。手动计划允许保留冲突并执行所列步骤，执行结果仍保留警告，页面不会自动修正方向。

## 逐次生成记录

“生成过程”逐次展示查询规则核对与比较、资料步骤核对的摘要：匹配数量、未核对的分句数量，以及是否出现冲突。已有的修正反馈、请求预算、实际请求次数和失败候选编辑入口保持可见。成功生成自动进入预览，执行仍由用户确认。

每次生成最多请求两次模型，预算没有增加。手动更改问题、编辑计划或更换数据会清除旧轨迹和预览；失败候选不会被标为有效草稿。模型文字、错误和反馈均按普通文本渲染。

## 界面验证范围

本轮独立浏览器检查使用模拟的 `task_checks` 报告和生成响应，配合真实本机预览、执行接口；共 17 个界面检查通过，真实模型请求为 0。检查涵盖：正确示例、反转比较方向、缺失资料步骤、执行后冲突警告、两轮核对摘要、自动预览与手动执行、失败候选保留、反馈文本安全呈现、问题/计划/数据修改后的失效，以及 390 px 视口无页面水平溢出。浏览器未记录页面脚本错误。

这些检查验证界面呈现，不证明规则判断准确或模型修正成功。真实模型评测与服务端规则测试以本轮评测报告为准。
