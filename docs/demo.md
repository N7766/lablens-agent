# 离线演示：比较 SFT 与 DPO

**模式：固定脚本回放，没有调用真实模型。** 该示例验证工具、计算、引用检查和展示路径；真实模式下的工具选择需要单独评测。

## 复现

```bash
lablens demo --output reports/offline-demo.json
uvicorn lablens.api:app --host 127.0.0.1 --port 8765
```

打开本地页面，点击“查看固定离线演示”，展开工具事件，可查看返回的源数据。

## 输入

> 比较 SFT 和最优 DPO 的准确率及输出长度，有什么结论边界？

## 工具顺序

1. `list_runs`：读取 11 条实验摘要。
2. `compare_runs`：比较 `run:sft` 与 `run:dpo-best`，返回确定性计算结果。
3. `search_notes`：检索验证集、统计显著性和长度单位说明。
4. 校验最终 JSON 结构和引用来源，输出结论。

## 本次实际输出

SFT 在验证集上答对 439/462（95.02%），DPO 答对 442/462（95.67%），增加 0.649 个百分点。

平均输出长度从 32.42 降至 31.53 个按空格切分的词，减少 2.76%。

这些实验使用了参与检查点选择的验证集，不能据此宣称独立测试效果、统计显著提升或推理时延/显存收益。
