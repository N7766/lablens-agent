# Round4 exposed development regression

This package preserves one run of six previously exposed Round3 conversation turns, eight unchanged synthetic documents and unchanged gold. It was executed and graded by an AI agent that participated in implementing the candidate. It is not a blind, independent-human, external-user, or production evaluation.

Read [REPORT.md](REPORT.md) for the result and limitations. Final report delivery: **0/6**; two submitted tasks timed out and four dependent turns were blocked. Retrieval coverage on submitted applicable turns: 2/2. No final answer exists to establish citation entailment or false-refusal quality. Six model attempts include four reported usages totaling 13,530 observed tokens and two unknown usages; total usage/cost is unknown.

Inputs, raw outputs and grading have separate frozen manifests. Historical Round3 labels inside the copied input/gold files are deliberately unchanged; this package and runner label their current use as exposed development regression.
