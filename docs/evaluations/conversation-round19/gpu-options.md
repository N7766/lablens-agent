## 预算如何计算

每项统一假设：100 GB 磁盘、2 小时计算、50 GB 入站下载、2 GB 出站；存储月费暂按 720 小时折算。

```text
预计美元费用 = 2 × dph_base
             + 100 × storage_cost × 2 / 720
             + 50 × inet_down_cost
             + 2 × inet_up_cost
```

这些数字没有计入税费、卡手续费和换汇费用，也没有覆盖超过 2 小时或超过假设的流量。固定镜像压缩层约 11.182 GB、权重文件约 15.231 GB，主要下载至少 26.414 GB，因此将入站规划从 30 GB 调高到 50 GB。镜像解压占用尚未实测，100 GB 分配量也不是已经验证足够；启动前仍须检查容器可用空间至少 40 GiB，必要时在创建前改为 120 GB 并重算费用。[模型元数据依据](model-selection.md) 未用未经核验的汇率把美元报价转换成人民币。

首选 A6000 的计算费约 1.0133 美元、100 GB 盘的两小时存储费约 0.0926 美元、假设流量费约 0.2800 美元，合计约 **1.3859 美元**。10 美元上限留有余量，但不应因此延长到无人值守运行。100 GB 存储若保留一天，按该 offer 当时运行态月费折算约 1.1111 美元；停止态实际价格可能不同，必须从实例报价核对。

## 部署相容性与执行要求

本轮目标为固定版本的 vLLM 0.32 CUDA 12.9 镜像。筛选要求 NVIDIA 驱动至少 `575.57.08`、优先 `580` 或更新版本，并要求 API 的 `cuda_max_good >= 12.9`；三项展示候选满足该元数据门槛。部署时仍需核对镜像 digest、容器架构、实际驱动和 GPU 启动结果，不能把报价筛选当成相容性验收。

- Linux `amd64`，单 GPU，基线系统 RAM 至少 32768 MiB，能分配至少 100 GB 磁盘；可靠性分数至少 0.99，有至少一个直接端口且合约剩余时长足够完成 2 小时。
- 普通 Vast 实例本身就是 Docker 容器，不能假设内部能再次运行 `docker compose`。将固定 vLLM 镜像作为实例镜像；SSH 启动模式会替换原镜像入口，需在 onstart 或登录后的受控脚本中显式启动服务。容器磁盘大小创建后不能直接扩容。[执行环境](https://docs.vast.ai/guides/instances/docker-environment)
- SSH 使用密钥认证。建议 vLLM 监听实例内 `127.0.0.1:8000`，通过 SSH 本地转发接入 LabLens；直接暴露 HTTP 时外部端口会由平台映射，不能假设仍为 8000。创建前须核验实际 SSH 模式与端口映射。[SSH](https://docs.vast.ai/guides/instances/connect/ssh)、[网络与端口](https://docs.vast.ai/guides/instances/connect/networking)
- 每次创建前重新读取实际 offer，核对总价、驱动、磁盘、带宽费率和租期；旧 offer ID 可能失效。这里只筛选按需，不选可能被抢占的报价。

## 结束与停止计费

停止 vLLM 进程、关闭 SSH 或浏览器都不会自行停止实例计费。`stop instance` 释放 GPU，保留数据并继续收取存储费用；重新启动不保证原 GPU 仍可用。[停止实例](https://docs.vast.ai/cli/reference/stop-instance)

验证完成先导出报告、日志、硬件和版本信息并校验本地文件，然后销毁**本次拥有的实例**，最后再次读取平台状态。容器磁盘随实例销毁；若另外创建了持久卷，卷会独立保留并继续计费，需要单独处理。[销毁实例](https://docs.vast.ai/cli/reference/destroy-instance)、[存储类型](https://docs.vast.ai/guides/instances/storage/types)

平台余额、进程 `timeout` 和本地定时器都不能单独证明已经停止收费。官方账单文档说明：余额归零后存储仍可能计费，保存的信用卡可能用于补收负余额。因此应以平台实例、卷及账单状态回读作为结束证据，而不是把充值额当作绝对支出上限。[账单说明](https://docs.vast.ai/guides/reference/billing)
