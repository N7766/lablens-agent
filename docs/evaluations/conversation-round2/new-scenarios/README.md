## 保留的首次结果与失败

- **larch-t2：答案正确，局部引用归因失败。**正确将对象由 Larch-12 更正为 Larch-14，得出 96 ms 延迟不达 80 ms 门槛、0.17% 失败率通过 0.5% 门槛。前两项结论却只引用测量文档，没有引用门槛所在协议。第三项综合结论同时引用协议与测量，故完整语义通过，但冻结的逐结论引用要求未全部通过。这不是检索缺失。
- **cedar-t1：正确处理总体冲突，复核又加入无根据的拒答。**162 ms 与 147 ms 两个总体 p95、150 ms 门槛及无权威记录的说明都正确。最终复核却新增机器分项“无权威记录确认分项数据有效性，故无法综合判定”，源文没有机器分项冲突，dashboard 明确不含分项测量。整体拒答合理；新增机器拒答不合理，完整报告不能通过。该新增项在提交 draft 中不存在，首次输出完整保留。
- **cedar-t3：数值正确，但未请求约定的澄清，且选错局部引文。**上一轮同时讨论 Vela-east / Vela-west，“那台机器”没有唯一对象。回答列出了两台机器的正确结果，却没有询问用户指哪台，未满足预先冻结的澄清要求。Vela-east 的 138 ms 结论选中的引文还是总体 162 ms 段落；完整来源块虽包含 138 ms，也不能把这个错选段落算作蕴含验证。

其他轮次正确完成本地双指标判断、用户更正后的指代与 16/24 ms 计算，以及平均功耗缺测和适配器额定功率的区分。持久中文、单位、合成本地范围限制 6/6 保留，没有生产外推。
