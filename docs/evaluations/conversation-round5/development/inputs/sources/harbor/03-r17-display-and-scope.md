# Harbor R-17 display precision and measurement scope
Document status: final companion note for Night Restore R-17.
Synthetic local evidence only.
The dashboard prints whole-number success percentages. Its displayed success percentages for both Quill and Sable are 99 percent. The signed counts, not these rounded dashboard percentages, control the acceptance calculation.
The R-17 evidence package provides no maximum recovery time after a power failure for either candidate. Such a value cannot be inferred from ordinary nightly median restore latency.
