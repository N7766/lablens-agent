# Round16 / 收尾第5轮：身份边界与本地超时诊断

基线：`5662c1090e1374b54017e14722660e51f6f55345`，分支 `codex/round16-workspace-auth`。2026-11-08 在实现及验证前记录；最终候选、结果和源文件哈希另存。上一轮原始失败不变。

## 验收范围

1. 默认要求身份配置；显式本地开发模式单独标识。数据库只保存密码哈希及会话令牌摘要，会话可到期和注销。登录没有公开注册；登录、会话和写操作有源站/CSRF边界。
2. 新建工作区与所有者绑定原子提交。列表按成员过滤。所有者管理成员；编辑者可写；只读成员可读但不能提交、取消、导入或建立索引。非成员不能用UUID访问旧、新接口。全局诊断仅管理员可读。
3. 历史无主工作区不归给第一个登录者；隔离后由管理员明确接管。已有所有者不能被接管。刷新、退出、会话到期不得继续显示前一账户资料；未知提交不自动重发。
4. JVM→Python任务/取消/索引和Agent→工具使用单独服务身份。Python所有旧、新API都验证身份，匿名请求在进入业务/模型前失败。服务凭据不进前端、不发给模型。
5. 保留现有资料版本审批、幂等与队列规则。权限测试不证明分布式费用上限、生产容量或回答正确性。

## 测试安排

- 先做 focused Python、Java真实MySQL、前端交互回归，再跑全套与CI。
- 单独数据库、Redis、RabbitMQ、8086/8770候选服务；不修改8081/8765主服务。证据只发布脱敏响应、判定和摘要，不发布口令、Cookie、CSRF或服务密钥。
- 浏览器使用专用合成工作区，完成登录→资料/免费检索→刷新历史→退出；无权限账户检查隔离。浏览器这部分是新工程验收，允许明确的无模型写操作，不复跑已封存模型题。
- 超时使用本机可控HTTP响应，协议和事件另存。**本轮外部模型与embedding调用预算为0**，运行环境不载入供应商密钥。
- 确认通过、失败、跳过分开记录；不合并PR、不升级主服务，不以工程结果填补Agent语义验收。
