- 只读复核发现 timeout counter 若只检查首尾为零，会漏掉 0→1→0；改为检查全部已观测值，并加负例。仍不能从离散采样排除两次采样间未知事件。

- 排空 90 秒只约束轮询与逐 ID 查询；在途 HTTP 和最后 worker 状态读取另计。协议明确这一边界，避免把软预算写成硬墙钟上限。
- 模型问题由另一 AI 开发代理依据官方 RabbitMQ 资料改编，固定为合成新样本。开发主体未为题目修改提示词或答案规则；独立 AI 出题不等于独立人工评测。真实调用前冻结源码、题目、标准和请求上限。
