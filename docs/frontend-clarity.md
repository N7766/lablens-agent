# 工作区界面精简

2026-11-14。本次只调整工作区前端的布局和文案，GPU 验收计划及主服务保持原状态。

## 改动

- 取消“保留来源”“添加、查看与删除”“新建、目标与限制”等重复辅助标签；独立提问不再重复展示模式，正常选中项目后不再常驻解释性提示。
- 项目选择、新建项目和资料列表位于侧栏上部；资料列表不随上传面板折叠。添加资料、成员与记忆管理退到次级入口。
- 会话选择放在提问区标题右侧，问题输入与提交构成主要操作路径；模式摘要保留实际选择。费用提示仅在远程模式显示，发送范围和明确许可仍保留。
- 结果正文、证据判定与展开来源沿用原结构；历史任务采用较轻的视觉层级，并显示当前选中项。窄屏次级项目操作并排收紧，减少资料区对首屏的占用。
- 保留表单语义标签、键盘焦点、状态公告、权限禁用和错误提示。只视觉隐藏重复的字段说明，不以 placeholder 替代表单可访问名称。

## 验证与难点

112 项现有前端测试通过，更新原结构测试以要求资料列表常驻，并扩充既有许可测试覆盖本地提示隐藏及生成/嵌入费用区分。浏览器实际检查空项目、资料列表、历史报告、证据展开、远程许可及修改问题后的许可失效。实测 1600 与 433 CSS 像素宽度均无横向溢出，控制台错误与警告为 0。

窄屏初版的侧栏操作仍纵向占用过多空间，随后改成紧凑网格；资料和状态保持可见，展开管理操作时占满整行。静态资源 URL 随文件内容更新，避免新 HTML 使用旧缓存。

浏览器预览使用当前源码及合成 API 资料；没有提交真实模型任务，没有重启或覆盖 8081 旧主服务，也没有将这次视觉检查计为模型或后端验收。
