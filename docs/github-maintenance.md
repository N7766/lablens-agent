# 展示与维护

首页用三个项目串起完整实践：DPO 的真实实验 → LabLens 的实验分析工具 → QuestionGlass 的桌面应用交付。README、可复现运行、真实失败记录和 Releases 比仓库数量更有说服力。

当前版本完成后，不安排自动空提交、倒填历史或机器人刷活跃。后续每次确有改进时，按“可复现问题 → Issue → 代码和必要测试 → 结果 → Release”留下记录。没有新工作时不需要制造动态。

下一轮值得投入的工作，需要新的证据或真实使用反馈：

- 由另一位评审者独立复核已保存答案，并与助手判断比较。
- 加入第二个真实实验项目，再检验导入与泛化；目前第二个数据集仅为合成夹具。
- 扩大预声明任务并重复运行；v0.9每题两次只检查有限波动，不能证明统计优势或覆盖真实使用。
- 如果确实部署到公网，再引入鉴权、费用配额和用户隔离；当前仅本地演示。

这些是下一轮研究方向，不作为当前 v0.9 的已完成功能。当前没有开启自动维护任务；发布应对应实际内容。
